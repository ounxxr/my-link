# [Wireframe] 마이링크 메인 화면 (방문자 프로필 뷰)

> **대상 화면:** 방문자가 접속 시 보게 되는 공개 프로필 페이지 (`/@username`)  
> **기준 뷰포트:** 모바일 퍼스트 (375px ~ 430px 기준, 데스크톱에서는 중앙 카드 레이아웃)  
> **디자인 테마:** Miro Canvas Grid & Clean White Card System

## 2. 세부 컴포넌트 명세

### 2.1 상단 액션 바 (Top Action Bar)
- **우측 공유 버튼**:
  - `32×32px` 원형 버튼 (`rounded-full`, `bg-slate-50`, `border border-slate-200`)
  - 탭/클릭 시 현재 브라우저 URL을 클립보드에 복사하고, 하단에 *"🔗 프로필 URL이 클립보드에 복사되었습니다!"* Toast 팝업 표시.

### 2.2 프로필 헤더 (Profile Header)
- **아바타 (Profile Avatar)**:
  - `80×80px` 완벽한 원형, 2px 외곽 테두리, 하단에 온라인 활동을 나타내는 그린 뱃지(`8×8px`).
- **사용자 이름 & 뱃지**:
  - `text-lg font-bold` (18px), 우측에 직무/카테고리 칩(`text-[11px]`, `rounded-full`).
- **유저네임 Handle**:
  - `text-xs text-slate-400` (`@jiyoon`).
- **한 줄 소개 (Bio)**:
  - `text-xs text-slate-600`, 행간 `leading-relaxed`, 중앙 정렬, 최대 폭 320px 제한.

### 2.3 SNS 아이콘 바 (Social Icon Bar)
- **버튼 규격**: `32×32px`, 원형 (`rounded-full`), 중앙 정렬 플렉스 박스.
- **지원 채널**: GitHub, Instagram, LinkedIn, Email, Blog 등.
- **인터랙션**: 호버 시 `scale-110` 확대, 탭 시 해당 소셜 채널 새 탭(`target="_blank"`) 열기.

### 2.4 섹션 구분 헤더 (Section Headers)
- 양옆으로 1px 헤어라인 디바이더(`h-px bg-slate-200`)와 가운데 `text-[11px] font-semibold text-slate-400` 대문자 텍스트 배치.

### 2.5 링크 버튼 카드 (Link Cards)
- **컨테이너 규격**:
  - 가로 폭 `100%`, 패딩 `14px 16px`, 모서리 둥글기 `rounded-xl` (12px).
  - 테두리: `border border-slate-200`, 배경 `bg-white`.
- **내부 구성**:
  - 좌측: `32×32px` 정방형 아이콘 박스 (이모지 또는 심볼 아이콘).
  - 중앙: 링크 제목(`text-xs font-bold`) + 서브 설명(`text-[10px] text-slate-400`).
  - 우측: 외부 이동 화살표 아이콘 (`ChevronRight`).
- **인터랙션**:
  - 마우스 호버 시 보더 컬러 강조(`hover:border-slate-400`) 및 부드러운 그림자(`hover:shadow-md`).
  - 클릭/터치 시 `active:scale-[0.98]` 미세 눌림 피드백.
  - 클릭 이벤트 발생 시 대상 링크의 `clickCount`를 LocalStorage에 +1 집계 후 새 탭으로 페이지 이동.

### 2.6 하단 푸터 (Footer)
- 서비스 워터마크 알약 뱃지 (`Created with MyLink`).
- 누르면 마이링크 메인 소개 페이지로 안내.
